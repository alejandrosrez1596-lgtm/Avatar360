# Avatar360

Avatar360 es un proyecto experimental que consiste en un avatar interactivo al que puedes realizar preguntas sobre el estado del arte en diferentes áreas del conocimiento. Su objetivo es facilitar el aprendizaje y la exploración de temas actuales mediante una interfaz conversacional intuitiva.

## Características

- Consulta sobre el estado del arte en diversas disciplinas.
- Interfaz amigable y fácil de usar.
- Ideal para estudiantes, investigadores y curiosos.

## Uso

Simplemente inicia el avatar y realiza tus preguntas para obtener información relevante y actualizada.
